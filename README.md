## Hey, I’m Loke

I’m an independent developer in Sweden. I make websites, tools, and software for the web. I like work that feels useful on day one and stays understandable six months later.

My usual mix is product UI, TypeScript, cloud platforms, CMS work, AI features, and the checks that keep a release from becoming a surprise.

## How I work

<p align="center">
  <img src="./assets/profile/toolkit.svg" alt="Focus areas: web products, cloud systems, open source, and AI workflows" width="100%" />
</p>

- Start with the actual problem, not the framework.
- Keep the first version small enough to finish.
- Test the risky parts before polishing the edges.
- Make the boring path clear for the next person.

I write about the same kind of work on [loke.dev](https://loke.dev), with practical guides, tools, comparisons, and notes from things I have actually built.

## What I am into right now

- Small developer tools that remove annoying setup work.
- AI features with clear limits and useful checks.
- Fast websites with content that is easy to update.
- Open source packages that do one job well.
